\# Image Caption Generator



\## 🚀 Overview

This project generates captions for images using deep learning.



\## 🧠 Model

\- CNN (InceptionV3) for feature extraction

\- LSTM for sequence generation



\## 📊 Dataset

Flickr8k dataset



\## ⚙️ Features

\- Image → caption generation

\- End-to-end pipeline

\- Streamlit web app



\## 🖥️ Demo

Upload image → get caption
